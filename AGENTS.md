# Treino Academia — Contexto do Projeto

## Visão Geral
Este diretório contém um programa de treino especializado para homens acima dos 50 anos, com adaptações específicas para condições de coluna como lordose lombar e escoliose. O projeto é focado em documentação de saúde e musculação (hipertrofia), não em desenvolvimento de software.

## Arquivo Principal
- **docs/index.html**: O núcleo do projeto. Um documento HTML completo e formatado que fornece:
    - **Base Científica**: guidelines baseadas em evidências para hipertrofia masculina 50+.
    - **Adaptações de Coluna**: princípios para treinar com lordose e escoliose, incluindo exercícios contraindicados (ex.: peso morto convencional, agachamento com barra nas costas).
    - **Estrutura de Treino**: split "Push / Pull / Legs" (PPL) otimizado para recuperação (3 sessões por semana).
    - **Treinos Detalhados**: exercícios, séries, reps e metas de "Reps in Reserve" (RIR) para cada dia.
    - **Cardio & Mobilidade**: recomendações de atividades complementares.
    - **Funcionalidades interativas**: checklist de exercícios com persistência em `localStorage`, notas pessoais, tema claro/escuro, exportação/importação de backup — tudo sem dependências externas (arquivo único, pronto para GitHub Pages).

## Uso
O conteúdo é uma referência para uma rotina de academia personalizada.
- **Visualização**: abrir `docs/index.html` em qualquer navegador.
- **Contexto para agentes de código**: usar as informações do `index.html` para responder perguntas sobre seleção de exercícios, frequência de treino ou precauções de segurança para o público-alvo.

## Princípios de Treino (Resumo)
- **Frequência**: 3× por semana (~55 min/sessão).
- **Intensidade**: RIR 2–3 (deixar 2–3 reps de reserva) para minimizar risco de lesão.
- **Recuperação**: 48–72h entre sessões.
- **Segurança**: evitar carga axial compressiva e manter coluna neutra.
- **Nutrição**: alta ingestão de proteína (~2.0–2.2 g por kg/dia) recomendada para adultos mais velhos.
